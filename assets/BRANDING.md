# OpenAI branding reference

- Symbol: OpenAI Blossom / interlocking six-ribbon knot icon.
- Source of vector geometry: Bootstrap Icons `openai` brand icon (https://icons.getbootstrap.com/icons/openai/). The OpenAI symbol itself is property of OpenAI; the two raster renditions use black and white as in OpenAI's brand usage guide.
- Official OpenAI brand guidance: https://openai.com/brand/
- Used solely alongside the displayed OpenAI service label. No claim of affiliation or endorsement by OpenAI.
- `openai-blossom-dark.png`: white symbol on transparent background for Dark Mode.
- `openai-blossom-light.png`: black symbol on transparent background for Light Mode.
- Do not redistribute these brand assets as the AI Limit Desk brand or apply arbitrary brand colors. The source license for the app's code does not override trademark restrictions.
